# Brand icons

These SVG logos are from `@lobehub/icons-static-svg` v1.101.0 (MIT),
<https://github.com/lobehub/lobehub>.

They are vendored here so the console can render provider and model marks
without adding a runtime dependency or a second icon system. Only the marks
actually used by the console are included. Do not hand-edit the SVG paths;
refresh them from the package when needed.
