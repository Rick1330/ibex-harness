# IBEX Management API

Python FastAPI management-plane service. The API contains both established tenant-management routes and **mounted-but-provisional** operator D1/D2 read contracts. A mounted route is not evidence of hosted production readiness.

## Route families

| Family | Representative routes | Authorization/boundary |
| --- | --- | --- |
| Probes | `/health`, `/ready`, `/metrics` | Public liveness; readiness checks AuthService/Postgres |
| Organizations, users, agents | `/v1/organizations/*`, `/v1/users/*`, `/v1/agents/*` | Bearer token, path `org_id` match, role/permission checks; cross-tenant IDs return 404 |
| Tokens/PATs | `/v1/tokens`, `/v1/tokens/{token_id}` | Token permissions; plaintext returned only on creation |
| Providers/credentials | `/v1/organizations/{id}/providers` | Owner/admin policy; API delegates secret sealing and metadata reads to AuthService |
| Rate cards, budgets, usage | `/v1/organizations/{id}/rate-cards`, `/budgets`, `/usage/query` | Tenant-scoped policy and billing permissions |
| Model policies | `/v1/organizations/{id}/model-policies` | Tenant-scoped CRUD and policy validation |
| Capture policies | `/v1/organizations/{id}/capture-policies` | Tenant-scoped CRUD/resolve; retention and redaction boundaries apply |
| Legal holds | `/v1/organizations/{id}/legal-holds` | Explicit legal-hold permission; audit trail required |
| Operator session | `/v1/operator/session/login`, `/refresh`, `/logout` | Server-owned session cookie, CSRF checks, AuthService/session integration; not a browser bearer shortcut |
| Operator D1 | `/v1/operator/context`, `/overview`, `/platform`, `/events` | Mounted, tenant-scoped, read/event transport; provisional until hosted identity/origin/reconnect evidence |
| Operator D2 | `/v1/operator/traces`, `/traces/{id}` | Metadata-only list/detail; strict schema, bounded projection, no raw content/prompts/tool args |
| OpenAPI | `/openapi.json`, `/docs` | Generated contract; verify with the repository snapshot gate |

The exact mounted route inventory is generated by `services/api/scripts/route_inventory.py`; contract changes require snapshot regeneration and Console runtime-contract updates.

## Authorization and tenancy

- Bearer routes authenticate through AuthService and establish `SET LOCAL app.current_org_id` before tenant database access.
- Operator session routes use server-owned cookies and CSRF protections; do not replace them with client-supplied organization IDs or browser bearer storage.
- Every query retains explicit `org_id` scoping even where PostgreSQL RLS is enabled. Cross-tenant resource identifiers return 404 to reduce enumeration.
- D1/D2 responses are `Cache-Control: no-store`; traces expose only the approved metadata contract.

## Configuration

| Variable | Purpose |
| --- | --- |
| `IBEX_API_DATABASE_URL` | Async PostgreSQL DSN |
| `IBEX_AUTH_GRPC_ADDR` / `IBEX_API_AUTH_GRPC_ADDR` | AuthService gRPC target |
| `IBEX_API_AUTH_TIMEOUT_MS` | Auth call deadline; default 50 ms |
| `IBEX_API_REDIS_URL` | Suspension/rate-limit pub/sub and idempotency support |
| `IBEX_API_CELERY_BROKER_URL` | Required for organization deletion enqueue; failure is fail-closed |
| `IBEX_API_HOST` / `IBEX_API_PORT` | Bind settings; default port 8010 |
| `IBEX_API_DOCS_BASE_URL` | Public error-docs URL prefix |

See [ENVIRONMENT_VARIABLES.md](../../web/engineering/ENVIRONMENT_VARIABLES.md) for the registry and [services/auth/README.md](../auth/README.md) for credential/session ownership.

## Local run and verification

```bash
cd services/api
uv sync --frozen --extra dev
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8010

# from repository root
services/api/.venv/bin/pytest -q services/api/tests
services/api/.venv/bin/python services/api/scripts/route_inventory.py --check
bash .github/scripts/check-openapi-snapshot.sh
```

## Readiness boundary

The API is locally testable and its D1/D2 contracts are mounted. Production promotion still requires AuthService/session/MFA integration, deployment-origin and CORS/CSRF evidence, two-tenant negative tests, redaction/hostile-content tests, performance/availability evidence, and rollback/incident runbooks. Do not describe the full management product, dashboard, or provenance inspector as complete until those gates are accepted.
