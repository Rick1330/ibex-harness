<StatusBadge status="new" /> Auth caching is **shipped** (milestone 2.2.1). Deep tuning guidance lands in a follow-up docs PR; this page is the navigation stub and source map.

<Callout type="info" title="What ships today">
  The proxy may cache successful token validations behind a bloom filter + LRU. Cache enablement requires a working Redis revocation channel so revokes invalidate hot entries. Design: [ADR-0028](/docs/adr/0028-auth-cache-design) and [ADR-0029](/docs/adr/0029-token-revocation-propagation).
</Callout>
