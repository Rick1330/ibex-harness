# Phase 3.5 — Tracks

<Callout type="note" title="Planning baseline">
  Tracks group milestones for planning. Preferred sequencing below is not a rigid schedule.
  Paths, libraries, and designs on linked milestone pages are orientation sketches — implementation
  is expected to require further research and may diverge.
</Callout>

## Track A — Worker Infrastructure

Celery + Redis is the preferred starting worker stack for bounded extraction tasks. Alternatives (Temporal, Arq, Dramatiq) remain open for later investigation if workload shape changes.

**Preferred sequencing within track:** `3.5.A.1 → 3.5.A.2`

- [3.5.A.1 — Celery Worker Skeleton](/roadmap/phase-3-5-extraction-assembly/milestones/3.5.a.1-celery-worker-skeleton)
- [3.5.A.2 — Task Observability & Dead Letter](/roadmap/phase-3-5-extraction-assembly/milestones/3.5.a.2-task-observability-dead-letter)
