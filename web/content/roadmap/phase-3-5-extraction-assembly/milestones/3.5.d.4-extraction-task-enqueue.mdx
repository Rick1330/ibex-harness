## Why This Milestone Exists

The proxy needs to mark sessions completed and trigger memory extraction once per completed
session. Checkpoints store hashes only (ADR-0032 / ADR-0064), so turn text is buffered
transiently in Redis on the chat path and read at terminate time.

Transport decision: the proxy does **not** speak Celery’s Redis wire protocol. It calls an
internal worker HTTP endpoint that runs `extract_session_memories.apply_async` in Python.
See [ADR-0072](/docs/adr/0072-extraction-enqueue-via-worker-http) (supersedes the earlier
LPUSH sketch on this page).
