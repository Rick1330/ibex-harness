## Why This Milestone Exists

Stand up a minimal, spec-compliant MCP server process that authenticates against the existing IBEX identity system and exposes zero tools yet — proving the transport, auth, and process-lifecycle plumbing work before any memory logic is added.

---

## Transport Decision (ADR-0043)

- **Streamable HTTP** as the only supported production transport
- **stdio** for dev-convenience only, gated behind `IBEX_MCP_TRANSPORT=stdio`
- **Python 3.11 + official `mcp` SDK** (`modelcontextprotocol/python-sdk`)
- New service `services/mcp-memory/` — separate lifecycle from proxy/API/context
