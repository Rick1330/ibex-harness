## Why This Milestone Exists

The Phase 3 Track B work already specified the `ContextRetriever.retrieve()` component well — launching directive/hot-cache/embedding concurrently via `asyncio.gather(..., return_exceptions=True)`, only starting cold search once the query embedding is ready, merging and deduplicating hot/cold results. This milestone **wires it into the assembly pipeline directly** and adds the pieces the original spec left implicit.

## Additions on Top of the Existing Retriever Design

### 1. History is request input — not a fourth I/O branch (correction)

An earlier sketch proposed a fourth concurrent `history_task` reading conversation text from the
session-checkpoint store. **That branch must not be implemented:**

1. `AssembleContextRequest.recent_messages` already carries history (zero I/O).
2. `ibex_core.checkpoints` stores `messages_hash` only — not message text.
3. `packages/session.Store` has no history-read API (proxy owns session checkpoints).

**Fix:** treat `recent_messages` as already-available input; count tokens into `history_tokens`
via `BudgetCalculator` (3.5.C.1). The orchestrator has **exactly three** concurrent I/O branches:
directive (Redis cache envelope), hot memories (`GET /v1/memories/hot`), and cold search
(`POST /v1/memories/search`, which embeds **server-side** — context must not pre-embed).

### 2. Outer deadline + per-branch timeouts

`IBEX_CONTEXT_TIMEOUT` defaults to **45ms** (fail-open). Directive (~5ms) and hot (~15ms) use
tighter budgets; cold uses the outer budget and often times out when the embedder is 100–500ms —
partial results (directive + hot) are the intended degradation.

### 3. Tenant scoping enforced at the data layer

Every hot-cache key and cold-search query is namespaced (`{org_id}:hot_memories:{agent_id}`) /
filtered by token `org_id`. Directive Redis keys use `{org_id}:directive:{agent_id}`.

### 4. `RetrievalResult` (internal Python; proto mapping deferred to 3.5.C.6)

```python
@dataclass
class RetrievalResult:
    directive: ResolvedDirective | None
    directive_outcome: BranchOutcome
    hot_memories: list[MemoryHit]
    hot_outcome: BranchOutcome
    cold_memories: list[MemoryHit]
    cold_outcome: BranchOutcome
    recent_messages: list[Message]
    history_tokens: int
    sources_available: frozenset[str]  # subset of {"directive","hot","cold"}
```
