## Why This Milestone Exists

Expose the two core memory operations as MCP tools with explicit, hand-declared JSON schemas.
`search_memory` and `write_memory` call the memory service HTTP API so authz and the 9-step write
pipeline stay single-sourced. Provenance for MCP writes is recorded as
`metadata.mcp_source="mcp_explicit"` ([ADR-0050](/docs/adr/0050-mcp-server-skeleton) stub
contracts; real pipeline is the memory service).

## Design Decision: MCP Writes Use the Standard Pipeline

`write_memory` via MCP is not a fast-path insert. It goes through validate → PII → dedup → embed →
near-dup → conflict → DB → cache → index via memory HTTP. Confidence defaults to 0.6. Write
authorization is the existing `MEMORY_WRITE` permission bit only.
