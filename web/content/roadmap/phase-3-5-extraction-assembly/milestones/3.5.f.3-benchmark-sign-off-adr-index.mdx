## Phase 3.5 Exit Criteria

1. Extraction worker converts a completed session into &gt;=1 correctly-categorized memory
2. Subsequent chat request transparently injects a relevant memory
3. Zero cross-tenant memory leakage across all ISO-* and ISO-MCP-* cases
4. Context assembly p95 &lt; 50ms at 20 concurrent requests; proxy overhead &lt;20ms p99
5. All 4 degradation-ladder levels independently verified
6. MCP tools function end-to-end, sharing one substrate with proxy path
7. MCP server fails closed on auth-service outage; independent rate-limit budget verified
8. All Phase 1, 2, and 3 regression tests pass with zero regressions
9. `make e2e-smoke-p3.5` exits 0
10. ADR-0038, ADR-0043, ADR-0044 published and indexed
