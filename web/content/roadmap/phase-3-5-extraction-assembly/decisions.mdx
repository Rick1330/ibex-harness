## Architectural decisions

| Decision | Rationale |
| --- | --- |
| Separate Python context service (not inline Go) | Ranking / packing / tiktoken stay in Python; proxy stays thin (ADR-0038) |
| gRPC AssembleContext with hard deadline | Bound hot-path latency; degrade rather than block chat (ADR-0071) |
| Relevance gate before composite score | Floor cosine excludes irrelevant-but-hot memories (ADR-0068) |
| DP packer over pure greedy | Recover budget utilization on adversarial sets (ADR-0069) |
| Locked formatter order + nonce | Deterministic injection; lost-in-the-middle mitigation (ADR-0070) |
| Batch extraction on session close | Cross-turn awareness + cost (ADR-0064 / ADR-0065) |
| MCP tools call memory HTTP (one substrate) | Same tenancy / write path as proxy-assembled memories (ADR-0050 + E.2) |
| MCP fail-closed on auth outage + org RPM budget | Independent of proxy rate limits (E.4) |
| ISO-MCP matrix live auth + Postgres | Defense-in-depth beyond unit mocks (F.2) |
