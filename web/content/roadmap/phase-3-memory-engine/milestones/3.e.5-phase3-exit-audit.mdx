### Audit scope (Tracks A–E)

- **Track A/B gaps:** schema drift between migration files and `DATABASE_SCHEMA.md`, HNSW parameter tuning evidence completeness
- **Track C/D gaps:** PII detector false-negative rate on the labeled test set, conflict-detection precision on ambiguous cases
- **Track E gaps:** any ISO-* test flakiness, benchmark baseline staleness

---

## Phase 3 Exit Criteria (Final Consolidated List)

1. Memory write pipeline (9 steps) passes all unit + ISO-* integration tests
2. HNSW recall@10 ≥ 98% and p99 < 100ms at 1M-row benchmark scale
3. Temporal-interval-aware conflict detection correctly distinguishes sequential-fact vs. true-contradiction cases, with zero unnecessary LLM calls on non-overlapping intervals
4. Retrieval-quality benchmark running in CI with a committed baseline
5. `search_memory`/`write_memory` MCP tools function end-to-end with full ClickHouse tracing
6. All 10+ ISO-* cross-tenant isolation cases pass, including the `memory_relationships` cross-org edge case
7. GDPR delete cascade verified end-to-end, including the MinIO-partial-failure orphan-detection path
8. All Phase 1 and Phase 2 security regression tests still pass with zero regressions
9. `make e2e-smoke-p3-memory` exits 0
10. Phase 3 memory ADRs published and cross-linked (next free numbers after ADR-0047)
11. **No proxy hot-path changes** — explicitly re-verified, since that's Phase 3.5's boundary
