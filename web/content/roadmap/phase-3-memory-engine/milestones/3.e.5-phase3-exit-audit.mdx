## Phase 3 Exit Criteria (Final Consolidated List)

Verified against live evidence at `45696a2`. MCP E2E criterion removed (Phase 3.5.E.2).

1. Memory write pipeline (9 steps) passes all unit + ISO-\* integration tests
2. HNSW recall@10 ≥ 98% on committed CI profile; 1M full-profile benchmark (p95 &lt; 30 ms / p99 &lt; 100 ms per ADR-0061) optional on smoke/fast profiles
3. Temporal-interval-aware conflict detection: sequential-fact auto-supersedes; overlapping intervals escalate; zero LLM on non-overlapping intervals
4. Retrieval-quality benchmarks in CI with committed baselines (HNSW, ranking-quality, write-pipeline)
5. All 12 ISO-\* cross-tenant isolation cases pass, including the `memory_relationships` cross-org edge case
6. Per-memory GDPR delete cascade verified (ISO-2.1: hard `DELETE` cascades `memory_labels`, `memory_relationships`, `memory_conflict_escalations`); org-scope deletion, MinIO archive purge, and partial-failure orphan-detection deferred to Phase 4.A.2 ([#641](https://github.com/Rick1330/ibex-harness/issues/641)) per [ADR-0060](/docs/adr/0060-memory-service-tenant-isolation)
7. Phase 1 and Phase 2 security regression tests pass (`security-integration`)
8. `make e2e-smoke-p3-memory` exits 0
9. Phase 3 memory ADRs published and cross-linked (0047–0049, 0052–0061)
10. **No proxy hot-path changes** — explicitly re-verified (Phase 3.5 boundary)
