# Milestone 3.9.2 — Context Assembly Load Test and Benchmark

**Status:** Planned  
**Goal:** [3.9 — Phase 3 quality gate](/roadmap/phase-3-memory-engine/goals#goal-39-phase-3-quality-gate)  
**Phase:** 3 — Memory Engine and Operator Platform  
**Estimated effort:** 2 days

---

## Why This Milestone Exists

Phase 3 adds a gRPC call to the proxy's critical path. ARCHITECTURE.md commits to p95 &lt; 50ms for context assembly. Under concurrent load, the context assembly service may queue requests and degrade. This benchmark validates the latency target holds under realistic load.

**Do not** load-test via an HTTP/JSON gateway. The production path is **native gRPC** (`AssembleContext` on `ibex.context.v1.ContextAssemblyService`). An HTTP adapter would measure a different stack and hide gRPC serialization / connection-pool behaviour.

---

## gRPC-native load test

Prefer one of:

1. **[ghz](https://ghz.sh/)** — proto-aware gRPC load generator
2. **k6 gRPC** (`k6/net/grpc`) — same VU staging as other k6 scripts

### Example: ghz

```bash
# benchmarks/ghz/context_assembly.sh (sketch)
ghz --insecure \
  --proto packages/proto/proto/ibex/context/v1/context.proto \
  --call ibex.context.v1.ContextAssemblyService/AssembleContext \
  -d @benchmarks/testdata/assemble_context_request.json \
  -c 50 -z 2m \
  --rps 0 \
  "${IBEX_CONTEXT_GRPC_ADDR:-127.0.0.1:50051}"
```

Thresholds (document in CI / BASELINE_PHASE3):

- p95 &lt; 50ms at 50 concurrent
- p99 &lt; 100ms
- error rate &lt; 0.1% (directive-only fallback responses are success, not transport errors)

### Example: k6 gRPC

```javascript
// benchmarks/k6/context_assembly_grpc.js
import grpc from "k6/net/grpc";
import { check } from "k6";

const client = new grpc.Client();
client.load(["packages/proto/proto"], "ibex/context/v1/context.proto");

export const options = {
  stages: [
    { duration: "30s", target: 20 },
    { duration: "2m", target: 50 },
    { duration: "30s", target: 0 },
  ],
  thresholds: {
    grpc_req_duration: ["p(95)<50"],
    // transport failures only — app-level fallback is not a failed RPC
  },
};

export default function () {
  client.connect(__ENV.IBEX_CONTEXT_GRPC_ADDR || "127.0.0.1:50051", { plaintext: true });
  const res = client.invoke(
    "ibex.context.v1.ContextAssemblyService/AssembleContext",
    JSON.parse(open("../testdata/assemble_context_request.json")),
  );
  check(res, { "status OK": (r) => r && r.status === grpc.StatusOK });
  client.close();
}
```
