## What Ships Today

<Callout type="note" title="Current capability boundary">
  **Shipped:** Auth (Go), Proxy (Go) with mock/live OpenAI + Anthropic + self-hosted
  OpenAI-compatible forwarding, model capability registry, tokenizer registry
  (G2.M1), non-streaming + streaming response pipelines (G3.M1–M2), auth cache,
  directives/injection, sessions/checkpoints, idempotency, ClickHouse traces,
  embedder (TEI + hosted + stub), MCP memory skeleton, local observability stack,
  shared packages, and this public site.
  Default non-production `IBEX_LLM_MODE=mock` answers registered models with HTTP 200; `live`
  needs `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, and/or `IBEX_SELFHOSTED_ENABLED` (mock is rejected
  when `IBEX_ENV=production`).
  **Not yet:** real memory write/search engine (Phase 3), context assembly on the hot path (Phase 3.5),
  management API/dashboard (Phase 4), org-wide HA observability.
</Callout>
