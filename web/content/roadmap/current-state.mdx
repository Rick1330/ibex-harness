## What Ships Today

<Callout type="note" title="Current capability boundary">
  **Shipped:** Auth (Go), Proxy (Go) with mock/live OpenAI + Anthropic + self-hosted
  OpenAI-compatible forwarding, model capability registry, tokenizer registry
  (G2.M1), non-streaming response pipeline (G3.M1), streaming response pipeline design
  (G3.M2 / ADR-0045), auth cache, directives/injection,
  sessions/checkpoints, idempotency, ClickHouse traces, shared packages, and this public site.
  Default non-production `IBEX_LLM_MODE=mock` answers registered models with HTTP 200; `live`
  needs `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, and/or `IBEX_SELFHOSTED_ENABLED` (mock is rejected
  when `IBEX_ENV=production`).
  **`501 PROVIDER_NOT_CONFIGURED`** means the model is not in the registry — not
  "forwarding missing." **Not shipped (Phase 2.5+ remaining):** embedding service, Python memory, context
  assembly, worker, management API, operator dashboard.
</Callout>

### Platform (Phase 1)

- Auth gRPC (`ValidateToken`, `ValidateAgent`, token lifecycle) with Argon2id-backed PATs
- Proxy auth middleware, agent verification, request normalization, stable error envelopes, rate limiting
- Security integration gate with cross-tenant denial matrix and CI enforcement
- Shared packages (`logger`, `metrics`, `telemetry`, `config`, `apierror`, `shutdown`, `reqid`, `ratelimit`, `crypto`, `permissions`, `provider`, ...)
- Postgres migrations with RLS; integration smokes for auth, proxy, and security paths
