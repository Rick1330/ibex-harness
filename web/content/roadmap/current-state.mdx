## What Ships Today

<Callout type="note" title="Current capability boundary">
  **Shipped:** Auth (Go), Proxy (Go) with mock/live OpenAI-compatible forwarding,
  auth cache, directives/injection, sessions/checkpoints, idempotency, ClickHouse
  traces, shared packages, and this public site. Default non-production
  `IBEX_LLM_MODE=mock` answers registered models with HTTP 200; `live` needs
  `OPENAI_API_KEY` (mock is rejected when `IBEX_ENV=production`).
  **`501 PROVIDER_NOT_CONFIGURED`** means the model is not in the registry — not
  “forwarding missing.” **Not shipped (Phase 3+):** Python memory, context
  assembly, worker, management API, operator dashboard.
</Callout>

### Platform (Phase 1)

- Auth gRPC (`ValidateToken`, `ValidateAgent`, token lifecycle) with Argon2id-backed PATs
- Proxy auth middleware, agent verification, request normalization, stable error envelopes, rate limiting
- Security integration gate with cross-tenant denial matrix and CI enforcement
- Shared packages (`logger`, `metrics`, `telemetry`, `config`, `apierror`, `shutdown`, `reqid`, `ratelimit`, `crypto`, `permissions`, `provider`, …)
- Postgres migrations with RLS; integration smokes for auth, proxy, and security paths

### Single provider E2E (Phase 2)

| Area | What shipped |
| --- | --- |
| Provider | Registry, OpenAI JSON + SSE, routing middleware, error mapping, Idempotency-Key |
| Auth cache | Bloom + LRU; Redis revocation channel |
| Directives | Postgres + Redis resolver; system-prompt injection |
| Sessions | Sticky `X-IBEX-Session-ID`, checkpoints, idle sweeper |
| Traces | Async ClickHouse writes (org-filtered; no prompt content) |
| Quality | Latency benchmark (2.6.1); exit gate (2.6.2) |
