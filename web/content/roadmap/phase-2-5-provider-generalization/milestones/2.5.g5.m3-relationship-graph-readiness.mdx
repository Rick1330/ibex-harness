## Why This Milestone Exists

The `memory_relationships` table already exists with the right shape (typed edges: `supersedes/contradicts/specializes/generalizes/merged_from/derived_from`) but lacks graph-traversal indexes needed for the recursive CTEs Phase 3's extraction worker will run at volume (e.g., "walk the supersession chain to the current version"). Adding the index and helper view now, as pure schema-readiness, avoids a performance cliff when Phase 3 starts writing relationship edges.

### Index

```sql
CREATE INDEX idx_memory_relationships_source_type
 ON ibex_core.memory_relationships(source_memory_id, relationship_type);
```

### Helper view

A helper view for recursive CTE traversal of supersession chains — the most common graph-walk pattern in the write pipeline's conflict detection and the read pipeline's "resolve to current version" logic.
