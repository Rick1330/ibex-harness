## Why This Milestone Exists

Tracks A–F delivered provider generalization, embedder, schema pre-work, and the MCP skeleton.
Phase 2.5 is complete when those seams work together as a coherent platform, observability is
operable locally (Prometheus/Grafana/Tempo/Loki), and a single verify gate proves the exit
criteria. This milestone is the explicit completion gate — analogous to [2.6.2](/roadmap/phase-2-single-provider/milestones/2.6.2-phase2-exit-gate).

Artefacts:

1. **Local LGTM stack** — `make observability-up` with provisioned dashboards (ADR-0051).
2. **`make verify-phase25`** — maps exit criteria to runnable checks + multi-service e2e.
3. **Thin K8s observability chart** — compose parity for kind/minikube (not full app Helm).
4. **Roadmap sign-off** — `current-state` + phase status completed; Phase 3 entry clear.
