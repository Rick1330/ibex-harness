# Milestone 4.D.1 — Authenticated Shell & Operational Overview

**Status:** Planned  
**Outcome:** An authorized operator enters a real application, selects an organization, sees platform health/freshness, and reaches every investigation surface.  
**Track:** [Track D — Operator Capability Slices](/roadmap/phase-4-multi-provider/tracks#track-d--operator-capability-slices)  
**Dependencies:** 4.P.0; 4.P.1; 4.P.2 query subset; 4.P.3 redaction defaults; 4.P.6 assurance harness mature enough for Playwright  
**Estimated effort:** 3 weeks

<Callout type="note" title="Completion contract">
  Docs-site pages and benchmark charts are not operator shell evidence. Consume generated SDK only against the live operator topology.
</Callout>

## Why this milestone exists

Proves the runtime and operator context before specialized screens consume deep data.

## Scope and deliverables

Operator app shell, org/role context, Overview, Agents/Resources, Explore entry, Incidents entry, Settings, breadcrumbs, global search entry, live/historical selector, connection state, and data-state components (empty/error/partial/stale/degraded).

## Contract and data requirements

URL state stores `org_id`, time range, filters, columns, and selected resource. No mutation controls beyond approved read-only actions in this slice.

## Product and UX requirements

Clear empty/error/partial/stale/degraded states; keyboard navigation; Explore-first IA (do not force agent-first navigation).

## Non-functional requirements

Four roles, two tenants, initial-read budget, axe, keyboard, no-cross-tenant, operator SSE reconnect gates pass.

## Verification gates

Internal allowlist and read-only flag. Disable route access independently. Playwright shell journeys upload traces/reports.

## Rollout and rollback

Creates the first end-to-end operator proof on top of Track P. **Trigger:** shell auth, org scope, or Overview health regressions. **Reversal:** disable the operator shell or individual routes independently behind the allowlist/read-only flag without changing Track P data. **Verify:** public docs remain available; login and deep links fail closed; recovery restores Overview and navigation after the flag is cleared.

## Findings addressed

F4-001, F4-002, F4-012.

## Exit checklist

- [ ] Operator origin smoke + Playwright four-role shell journeys green.
- [ ] Org switch and URL state round-trip proven.
- [ ] Cross-tenant shell isolation evidenced.
- [ ] Rollback of routes demonstrated without data loss.
