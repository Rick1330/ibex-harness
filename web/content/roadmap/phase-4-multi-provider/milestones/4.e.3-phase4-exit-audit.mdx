## Why This Milestone Exists

Every prior phase's real completion evidence lived in a dedicated exit-audit artifact. Phase 4 adds a new human-facing attack surface (dashboard, multi-provider credentials) plus a second live upstream provider — it needs the same rigor as Phase 1's audit, not a lighter one.

---

## Exit Criteria (10-point sign-off)

1. Second live LLM provider (Anthropic) passes same test depth as OpenAI
2. `Registry.For(model)` resolves both providers with zero handler/middleware changes
3. Circuit breaker and opt-in fallback verified via 4.E.2's fault-injection suite
4. Redis Lua hierarchical rate limiting passes concurrency over-admission test (zero tolerance)
5. Dashboard E2E suite (4.E.1) green in CI, required on `main`
6. Zero axe-core `serious`/`critical` accessibility violations
7. Management API OpenAPI spec consumed by dashboard client with zero manual type overrides
8. All Phase 1–3.5 regression suites green with 2 providers registered
9. Phase 4 gap register published with zero open P0 gaps
10. `CURRENT_STATE.mdx` and roadmap snapshot updated
