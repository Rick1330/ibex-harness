## Why This Milestone Exists

Operators need a self-service surface for issuing, scoping, and revoking Personal Access Tokens (PATs). The API documentation already specifies the schema and permission model; this milestone wires those specifications into the management API. One critical invariant: the API server should never touch the token hash table directly — all revocation goes through `AuthService.RevokeToken` gRPC, mirroring the proxy's own "gRPC to auth, not direct DB" rule.

## Token Schema

```python
class TokenCreateRequest(BaseModel):
 name: str # human-readable label
 permissions: list[str] # ADR-0009 strings
 allowed_ips: list[str] | None = None # CIDR syntax only; not persisted
 expires_at: datetime | None = None
 agent_id: UUID | None = None

class TokenCreateResponse(BaseModel):
 id: UUID
 name: str
 token: str # plaintext — shown once
 permissions: list[str]
 prefix: str
 expires_at: datetime | None
 created_at: datetime

class TokenResponse(BaseModel):
 id: UUID
 name: str
 permissions: list[str]
 prefix: str
 expires_at: datetime | None
 created_at: datetime
 revoked_at: datetime | None
 is_revoked: bool
```

## Permission Strings

Scoped permission strings map to the existing 64-bit permission bitmap (ADR-0009):

| Permission String | Bitmap Bit | Description |
| --- | --- | --- |
| `memory:read` | bit 0 | Read memories |
| `memory:write` | bit 1 | Create/update memories |
| `memory:delete` | bit 2 | Delete memories |
| `session:create` | bit **16** | Start proxy sessions |
| `admin:user_manage` | bit **32** | Manage users |
| `admin:org_manage` | bit **35** | Org settings (alias OrgSettingsWrite) |
| `admin:token_create` | bit **36** | Issue tokens |
| `admin:token_revoke` | bit **37** | Revoke tokens |

Full catalog is in `API_DOCUMENTATION.md` Permissions Reference and `app/permissions_codec.py`.

## Business Rules

- **Plaintext shown exactly once**: on `POST`, Auth generates/hashes (Argon2id) and returns plaintext once.
- **Revocation via gRPC only**: `DELETE` calls `AuthService.RevokeToken` — never direct token-table writes.
- **IP restriction validation**: `allowed_ips` CIDRs validated syntactically; not stored (follow-up for persistence).
- **Permission scope enforcement**: caller cannot grant permissions they do not hold → `403 PERMISSION_ELEVATION_DENIED`.
