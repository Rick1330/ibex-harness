# Milestone 4.P.0 — Runtime Topology & Environment Contract

**Status:** Planned  
**Outcome:** A chosen deployment topology supports a server-capable operator UI or a static SPA with a separately deployed API/SSE origin across local, preview, staging, and production.  
**Track:** [Track P — Operator Readiness, Evidence & Control Plane](/roadmap/phase-4-multi-provider/tracks#track-p--operator-readiness-evidence--control-plane)  
**Dependencies:** Track A API foundations; Phase 3.5; 4.C.5 streaming baseline (implementation retained; soak evidence still required)  
**Estimated effort:** 2 weeks  
**Gate:** G0 topology

<Callout type="note" title="Completion contract">
  This milestone is complete only when the topology ADR, environment matrix, smoke transcript (login, API, operator SSE connect/reconnect/drain), and rollback procedure exist. Static `web/out` documentation deploy is not operator runtime evidence.
</Callout>

## Why this milestone exists

Without an explicit runtime decision, every Track D estimate assumes an authenticated realtime app that the current static docs site cannot provide (F4-001).

## Scope and deliverables

- Record the topology decision in an ADR (server-capable Next.js app **or** static SPA + separate API/SSE origin).
- Provision origins, TLS, CORS, CSRF, cookie/token audience, refresh rotation, SSE ingress timeouts, reverse-proxy buffering, and environment variables for local/preview/staging/production.
- Expose health, readiness (dependency-aware, not startup-only — F4-020), startup, and drain endpoints.
- Probe operator-event SSE separately from provider token streaming.

## Contract and data requirements

- Versioned API envelope: tenant, session, API version, pagination, error model.
- **Operator-event SSE:** event framing, reconnect, and `Last-Event-ID` resume semantics.
- **Provider token streaming:** continues to forward upstream SSE verbatim without adding event IDs or re-framing (ADR-0027; F4-007).
- Keep the public documentation site deployment separate from the operator application.

## Product and UX requirements

The shell shows connection state, freshness, live/historical mode, reconnecting, degraded, and drained states. Deep links are origin-safe and do not embed secrets.

## Non-functional requirements

No static export for authenticated realtime behavior. Staging API p95 metadata request within declared budget; operator SSE reconnects without duplicate visible events; termination drains active streams; SSE write deadlines and shedding hooks exist or are scheduled with evidence (F4-033).

## Verification gates

Smoke test login, API request, operator SSE connect, reconnect with `Last-Event-ID`, and graceful drain in the chosen topology. Validate static-export guards and origin/CORS/CSRF negative tests. Document environment matrix and rollback to public docs origin.

## Rollout and rollback

**Trigger:** topology misconfiguration, cookie/CORS failure, or stream memory growth. **Reversal:** dark-deploy behind internal flag; route traffic to the public docs site and disable operator origin without changing stored data. **Verify:** public site serves; operator origin rejects unauthenticated access; smoke transcript attached.

## Findings addressed

F4-001, F4-007, F4-020, F4-033.
