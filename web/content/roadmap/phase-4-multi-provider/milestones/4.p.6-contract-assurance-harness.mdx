# Milestone 4.P.6 — Contract & Assurance Harness

**Status:** Planned  
**Outcome:** Every capability produces machine-verifiable release evidence in the intended operator environment.  
**Track:** [Track P — Operator Readiness, Evidence & Control Plane](/roadmap/phase-4-multi-provider/tracks#track-p--operator-readiness-evidence--control-plane)  
**Dependencies:** 4.P.0; 4.P.2 fixtures can start early; must mature before 4.D.1  
**Estimated effort:** 3 weeks  
**Gate:** G6 assurance

<Callout type="note" title="Completion contract">
  A static-site smoke test is not dashboard E2E. Real PostgreSQL RLS, Redis Lua rate limiting, pgvector, and token-revocation paths must not be replaced by contract doubles.
</Callout>

## Why this milestone exists

A test file or planned route is not an acceptance gate until CI executes it against the intended topology and data (F4-012, F4-034).

## Scope and deliverables

- Generate TypeScript SDK from OpenAPI in CI; schema snapshots; old/new compatibility; migrations-from-zero and upgrade tests.
- Golden fixtures: trace/session/memory/cost; OTel round-trip; tenant/security matrix; Playwright (four roles, two tenants); axe; keyboard; k6; chaos; SLO gates.
- Explicit Playwright browser install and operator environment provisioning.
- Required-check inventory including Python gate and Semgrep security findings intended to block merges (F4-034).
- Trace/report uploads on failure; no-check fail-closed evaluation.

## Contract and data requirements

Evidence artifacts immutable and tied to commit, image digest, schema version, environment, test command, result, artifact links.

## Product and UX requirements

Fixtures cover loading, empty, error, partial, permission, stale, sampled, redacted, and expired states.

## Non-functional requirements

Promotion-blocking evidence must include Org B API/UI reads and searches against Org A data: direct lookups return `404` and searches return an empty set.

## Verification gates

Required CI jobs green on operator topology; cross-tenant denial reports; accessibility and performance reports uploaded.

## Rollout and rollback

**Trigger:** missing required check or false-green smoke. **Reversal:** failed gate blocks promotion; does not silently downgrade to public-site smoke. **Verify:** evidence bundle lists all required artifacts for a sample capability.

## Findings addressed

F4-012, F4-028, F4-029, F4-030, F4-034.
