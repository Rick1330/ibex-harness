## Design note: RLS Session Variable

Every existing service in this codebase double-enforces tenant isolation: RLS **and** application-layer `WHERE org_id = ...`. The API server's DB session dependency sets `app.current_org_id` via `set_config(..., true)` at the start of every request transaction (from the verified token's `org_id`, never from a path/body param), so that Postgres RLS policies are the backstop even if a router forgets a `WHERE` clause.

```python
# Live pattern in services/api/app/db.py
await session.execute(
    text("SELECT set_config('app.current_org_id', :org_id, true)"),
    {"org_id": org_id},
)
```
