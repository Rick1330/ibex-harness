## Why this milestone exists

This is the differentiated product wedge: an **auditable context-and-policy provenance debugger**, not a generic APM clone (F4-003, F4-009).

## Scope and deliverables

### Explore

Global query bar with autocomplete, facets, saved-view-ready URL grammar, results for traces/sessions/failures, preserve list filters when opening detail.

### Trace Inspector — three-layer progressive disclosure

1. **Summary strip:** agent/session/model/provider, tokens, latency stages (label unavailable stages), completeness/sampling/freshness/retention badges.
2. **Candidate matrix:** sortable rows with score contribution, rank, Δrank vs similarity, category, tokens, disposition; exclusion groups **Included / Budget-excluded / Filtered / Failed**.
3. **Explain tree (selected item):** additive waterfall or stacked contribution for composite weights **`0.40 / 0.25 / 0.20 / 0.10 / 0.05`**; keep score / rank / resource / outcome semantics separate.

Also: timeline/flame view, directive+routing decision links, tools timeline, model/fallback, evaluation links, redacted JSON, copy-link, bidirectional pivots.

### Reproducibility contract

Surface weights, half-lives, tokenizer/packing policy versions, replay status, and directive version hash used at inference time.

## Contract and data requirements

Stable Trace/Span DTO with server-enforced `org_id` scope; copyable IDs (`trace_id`, `span_id`, `request_id`, `session_id`, `checkpoint_id`); completeness, sampling, freshness, retention, provenance links. Org B lookups against Org A IDs return `404`; searches return empty.

## Product and UX requirements

Safe rendering of hostile prompt/tool content (F4-008). Never infer success from missing data. Live selection freezes before detail. Keyboard-safe panels; axe; screen-reader-visible status changes. Metadata-only launch before redacted expansions.

## Non-functional requirements

Golden multi-step trace; point lookup by known IDs; query and page-load budgets; assembly correctness prerequisites F4-028–031 either fixed or residual-risk accepted with UI labels.

## Verification gates

Golden-trace fixture asserts joinable summary, assembly stages, selected/excluded memories, conversation source state, tool events, and raw JSON authorization state. Cross-tenant denial. Accessibility suite. Performance budget report.

## Rollout and rollback

**Trigger:** content expansion leaks, inspector latency/SLO breach, or cross-tenant provenance joins. **Reversal:** disable content expansion and restore metadata-only trace views. **Verify:** Explore lists remain available; expanded payloads stay redacted or hidden until the flag is restored.
