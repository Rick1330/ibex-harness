# Phase 6 — Goals (Intelligence & Monetization)

**Status:** Planned (stub)  
**Entry:** Phase 5 exit (or earlier if pulled forward)  
**Why this phase exists:** Phase 3 milestones (3.1.1, 3.9.3) promised Phase 4 would include behavioural fingerprinting, drift metrics, and billing readiness. Phase 4's actual goals are multi-provider only (4.1–4.3). This stub records the deferred scope so documents stop disagreeing.

## Goal 6.1: Behavioral fingerprints

**Description:** Persist per-agent behavioral fingerprints (`ibex_core.behavioral_fingerprints`) as sketched in 3.1.1.

**Acceptance criteria (draft):**

- Schema + ADR before first write path
- Tenant-scoped RLS
- No raw memory `content` in fingerprint rows or logs

## Goal 6.2: Drift detection and alerts

**Description:** Drift metrics and `ibex_core.drift_alerts` with operator-visible alerts.

**Acceptance criteria (draft):**

- Documented detection window and severity levels
- Alert path does not block proxy hot path

## Goal 6.3: Billing and cost conversion

**Description:** Convert token usage into provider-priced dollars for ARR / cost-per-1M metrics (PROJECT_CONTEXT business metrics). Phase 3 analytics (3.6.7 / 3.8.5) track tokens only today.

**Acceptance criteria (draft):**

- Provider price table (config or DB) with effective dates
- Analytics API exposes cost alongside tokens
- Audit log for price changes

## Non-goals (remain Phase 4)

- Provider adapters, routing/failover, hierarchical Redis rate limits
