This page is the route inventory for the Go proxy. The behavioral pages cover [chat completions](/docs/api-reference/chat-completions), [errors](/docs/api-reference/errors), and [health](/docs/api-reference/proxy-health). The auth gRPC contract is documented separately.

## Public (no auth)

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/health` | Liveness |
| `GET` | `/ready` | Readiness (`auth_grpc`, `redis`) |
| `GET` | `/metrics` | Prometheus text exposition |

Public handlers are registered without method-specific ServeMux patterns. Integrators should call `GET` (Prometheus scrapers also use `GET`/`HEAD` conventions).

## Protected

| Method | Path | Auth | Notes |
| --- | --- | --- | --- |
| `GET` | `/v1/internal/auth-probe` | PAT + agent | Returns `{org_id, permissions}`; non-`GET` → `405 METHOD_NOT_ALLOWED` |
| `GET` | `/v1/orgs/{org_id}/auth-probe` | PAT + agent | Path org must match token org; non-`GET` → `405` |
| `POST` | `/v1/chat/completions` | PAT + agent + `ProxyChatCompletion` | Chat forwarding, JSON or SSE; non-`POST` → `405` |
| `POST` | `/v1/responses` | PAT + agent + `ProxyChatCompletion` | Responses subset; non-streaming and capability-gated |
| `POST` | `/v1/sessions/{session_id}/terminate` | PAT + agent + `SessionTerminate` | Complete a session and enqueue extraction |

Tenant scope for chat comes from the **token**, not the URL. See [Chat completions](/docs/api-reference/chat-completions) and [Proxy overview](/docs/proxy/overview).

## Not listed here

- Management API and Console routes — [Management API](/docs/api-reference/management-api); provisional and not part of the proxy contract
