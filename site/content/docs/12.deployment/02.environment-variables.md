IBEX services load configuration from environment variables at startup via `packages/config`, and the Python services use `pydantic-settings`. Missing required values fail fast with a clear message — there are no checked-in `.env` files, only `.env.example` references per service. The Go and Python services do not auto-load a `.env` file; Nuxt is the exception and loads `services/console/.env` during `nuxt dev` and `nuxt build`.

::callout
---
{"type":"tip","title":"Full registry"}
---

  Operators and platform engineers should also read `engineering/ENVIRONMENT_VARIABLES.md` in the repository for production profiles and Python-service variables.

::

## Conventions

- Prefix `IBEX_` for project-wide settings; `POSTGRES_` / `REDIS_` / `CLICKHOUSE_` / `OPENAI_` for infrastructure and providers.
- Secrets (DSNs, API keys, Redis passwords) never belong in git — inject via your secret manager.
- Precedence: process environment → documented defaults. The dev Compose Make targets pass `infra/compose/dev/.env.example` with `--env-file`, and a variable exported in the shell overrides it.

## Proxy

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `IBEX_AUTH_GRPC_ADDR` | `string (host:port)` | Yes | Auth gRPC target for ValidateToken and ValidateAgent. |
| `IBEX_AUTH_GRPC_CA_FILE` | `string (path)` | Outside development | PEM CA bundle that verifies the AuthService gRPC certificate. Outside development the proxy pins this CA and fails startup if it is missing. Development may omit it for the plaintext local AuthService. |
| `REDIS_URL` | `string (URL)` | No | Redis for rate limiting, auth-cache revocation subscribe, idempotency, and /ready. Empty uses Noop limiter. |
| `POSTGRES_DSN` | `string (postgres://…)` | No | Enables directives and sessions on the proxy. Empty → Noop stores. |
| `IBEX_LLM_MODE` | `enum` | No | `mock` (default deterministic provider) or `live` (requires a provider key). Mock forbidden in production. |
| `OPENAI_API_KEY` | `string` | No | Required when IBEX_LLM_MODE=live. |
| `OPENAI_BASE_URL` | `string (URL)` | No | OpenAI-compatible API base URL. |
| `IBEX_AUTH_CACHE_ENABLED` | `boolean` | No | Enable bloom+LRU auth cache when Redis is healthy. |
| `IBEX_PORT` | `integer` | No | HTTP listen port for /health, /ready, /metrics, and /v1/* routes. |
| `IBEX_AUTH_VALIDATE_TIMEOUT` | `duration` | No | Per-request auth gRPC budget. Use 2s locally; production target is 50ms. |
| `IBEX_RATE_LIMIT_DEFAULT_RPM` | `integer` | No | Default org requests-per-minute when Redis is available. |
| `IBEX_MAX_REQUEST_BODY_BYTES` | `integer` | No | Max chat POST body size (see ADR-0013). |
| `IBEX_IDEMPOTENCY_TTL` | `duration` | No | Idempotency-Key retention for non-streaming chat. |
| `CLICKHOUSE_DSN` | `string` | No | Enables async llm_traces. Empty disables writer (fail-open). |
| `IBEX_ERROR_DOCS_BASE` | `string (URL)` | No | Optional base for error envelope docs_url fields. |

Read `services/proxy/.env.example` and `services/auth/.env.example` for the variable names, then export the values in
the host process environment before running those services. Copying an example file alone does not load it. More knobs
(session sweep, OpenAI retries, cache bloom size): [Proxy configuration](/docs/proxy/configuration).

## Auth

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `POSTGRES_DSN` | `string (postgres://…)` | Yes | Postgres for tokens and agents. Compose: postgres://ibex:ibex@localhost:5432/ibex |

| `IBEX_AUTH_GRPC_TLS_KEY_FILE` | `string (path)` | Conditional | PEM private key for the AuthService gRPC listener. Secret; never mount into another service. |
| `JWT_PRIVATE_KEY_FILE` | `string (path)` | Conditional | File form of `JWT_PRIVATE_KEY_PEM`, used when the inline PEM is empty. A set-but-unreadable file fails startup. |
| `IBEX_AUTH_POLICY_SIGNING_KEY_FILE` | `string (path)` | Conditional | File form of `IBEX_AUTH_POLICY_SIGNING_KEY_PEM`. Required outside `development`, in either form. |
| `IBEX_PORT` | `integer` | No | HTTP port for /health, /ready, and /metrics. |
| `IBEX_GRPC_PORT` | `integer` | No | gRPC listen port for AuthService (internal only). |
| `IBEX_AUTH_VALIDATE_RPM` | `integer` | No | ValidateToken rate limit when Redis is set. |
| `POSTGRES_TEST_DSN` | `string` | No | Integration tests on compose test port 5433. |

Run `make db-migrate` after compose is healthy.

## Operator API

The Management API reads `IBEX_API_*` names and accepts the aliases below for operator settings
(`services/api/app/config.py`).

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `IBEX_API_DATABASE_URL` | `string (postgresql+asyncpg://…)` | Yes for database-backed API | Async SQLAlchemy/PostgreSQL DSN for the Management API. Do not use the Go services' `POSTGRES_DSN` name or `postgres://` driver scheme here. |
| `IBEX_AUTH_GRPC_CA_FILE` | `string (path)` | Outside development | PEM CA bundle that verifies the AuthService gRPC certificate. Required outside development; every API AuthService channel uses TLS 1.2+. Development may omit it for the trust-gated plaintext path. |
| `IBEX_OPERATOR_FEATURE_ENABLED` | `boolean` | No | Kill switch for the operator session and SSE routes. Default `false`; when false those routes return `503`. Enabling it requires `IBEX_ENV` to be set explicitly. |
| `IBEX_OPERATOR_ALLOW_RAW_READ` | `boolean` | No | Per-action switch for operator raw-read. Default `false` (deny). |
| `IBEX_OPERATOR_ALLOW_EXPORT` | `boolean` | No | Per-action switch for operator export. Default `false` (deny). |
| `IBEX_OPERATOR_ALLOW_DELETE` | `boolean` | No | Per-action switch for operator delete. Default `false` (deny). |
| `IBEX_OPERATOR_ALLOW_REPLAY` | `boolean` | No | Per-action switch for operator replay. Default `false` (deny). |
| `IBEX_OPERATOR_ALLOW_SECRET_USE` | `boolean` | No | Per-action switch for secret use. Default `false` (deny). |
| `IBEX_OPERATOR_EVENTS_CHANNEL` | `string` | No | Redis pub/sub channel for operator-event fan-in. Default `ibex:operator:events`. |
| `DASHBOARD_JWT_PUBLIC_KEYS_FILE` | `string (path)` | Conditional | File form of `DASHBOARD_JWT_PUBLIC_KEYS_PEM`, used when the inline PEM is empty. A set-but-unreadable or empty file fails startup. |

File-backed PEM variables exist because a Compose `.env` cannot carry a multi-line PEM. Inline values always win when
both forms are set.

## Console (server-only BFF)

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `IBEX_OPERATOR_API_ORIGIN` | `string (origin)` | Yes for live data | Server-only origin of the Management API, read by `services/console/server/utils/operator/http.ts`. Absent → `503 API_ORIGIN_UNAVAILABLE`. An origin only: no path, query, fragment, or userinfo; a request carrying a session cookie requires HTTPS. |
| `IBEX_OPERATOR_API_INTERNAL_ORIGIN` | `string (origin)` | No | Server-only origin used only by the Console `/ready` probe, which calls `<origin>/health` without credentials and a 2 s timeout. Absent → `200 {"status":"ok","upstream":"unchecked"}`. Never exposed to the browser. |
| `IBEX_OPERATOR_SESSION_COOKIE_NAME` | `string` | No | Cookie the BFF forwards to the API. Default `ibex_session`. |
| `NUXT_PUBLIC_IBEX_ENV` | `string` | No | Non-secret environment label rendered in the UI. Default `local`. Never put a credential here. |
| `CONSOLE_READ_ONLY` | `boolean` | No | Reserved. The Nuxt implementation does not consult it; read-only behaviour is structural because the Console exposes no mutation routes. |

## Relay

The evidence relay daemon is **default-off** and is not part of the certified compose
profile. See [ADR-0085](https://github.com/Rick1330/ibex-harness/blob/main/engineering/adr/0085-evidence-relay-daemon-and-session-fence.md) and
`services/relay/README.md`.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `IBEX_RELAY_ENABLED` | `boolean` | No | Explicit gate. Disabled exits 0 without connecting; enabling requires both DSNs. |
| `IBEX_RELAY_POSTGRES_DSN` | `string (postgres://…)` | Yes | Outbox authority. Pinned to role `ibex_evidence_relay` per connection; membership is a deployment prerequisite. |
| `IBEX_RELAY_CLICKHOUSE_DSN` | `string (clickhouse://…)` | Yes | Projection sink (non-production pilot; G4-gated). |
| `IBEX_PORT` | `integer` | No | HTTP port for /health, /ready, and /metrics. |

::callout
---
{"type":"warning","title":"Set the Proxy runtime profile explicitly"}
---

  Proxy startup rejects missing/empty `IBEX_ENV`; it must not silently assume `development`. Staging/production also reject a missing `REDIS_URL`. If configured Redis is unreachable during a limiter operation, the Proxy returns `503 SERVICE_DEGRADED` before provider work; auth-cache wrapping is skipped when its revocation channel is unavailable. Readiness reports required Redis health — see [Proxy health](/docs/api-reference/proxy-health) and [ADR-0081](https://github.com/Rick1330/ibex-harness/blob/main/engineering/adr/0081-fail-closed-proxy-runtime-controls.md).

::

## Local environment layout

The `.env.example` files are reference lists, not runtime configuration: the Go and Python services do not load a
`.env` file, so copying one sets nothing for them. Read them for the expected names, then export the values in the shell
that starts the service (or pass `--env-file` to Compose for the dev data stores). Nuxt is the exception: `nuxt dev` and
`nuxt build` in `services/console` load a `.env` from that directory, where `NUXT_PUBLIC_IBEX_ENV` changes the displayed
environment label; the built Console server reads the process environment.

```bash
export IBEX_AUTH_GRPC_ADDR=127.0.0.1:9091
export IBEX_AUTH_VALIDATE_TIMEOUT=2s
```

Database DSN variables and schemes differ by service: the Go auth/proxy use `POSTGRES_DSN=postgres://...`, while the
Python Management API uses `IBEX_API_DATABASE_URL=postgresql+asyncpg://...`. Use the variable and scheme shown for the
service rather than sharing one value.

Reference files: `services/proxy/.env.example`, `services/auth/.env.example`, `services/relay/.env.example`,
`services/memory/.env.example`, `services/embedder/.env.example`, `services/mcp-memory/.env.example`,
`services/mcp-operator/.env.example`, and `infra/compose/dev/.env.example`.
