Local development runs the data stores plus the Worker and Worker Beat containers in Docker; most other application
services run on the host for fast iteration. The compose file under `infra/compose/dev/` defines `postgres`, `redis`,
`clickhouse`, `minio-init`, `minio`, `worker`, and `worker-beat`.

::callout
---
{"type":"warning","title":"Development stack, not the v1.0 deployment profile"}
---

  This page documents the **development dependency stack**. It starts data stores and the two worker containers; the
  remaining application services normally run on the host for iteration. This is **not a supported deployment**.

  The supported v1.0 profile is `v1-single-node`
  ([ADR-0097](https://github.com/Rick1330/ibex-harness/blob/main/engineering/adr/0097-v1-supported-profile.md)): one
  Compose project that runs every required service as a container behind an edge TLS terminator. See
  [v1-single-node profile](/docs/deployment/v1-single-node). No deployment claim in this repository is backed by this
  development compose file. Do not point a production install at it.

::

::callout
---
{"type":"note","title":"Prerequisites"}
---

  Docker Compose v2, GNU Make, Git Bash on Windows, and ports **5432**, **6379**, **8123**, **9002**, **8006–8007**,
  and **9100–9101** available. See the [Quickstart](/docs/getting-started/quickstart) for the five-minute path.

## Compose services and ports

| Service | Image | Host port | Purpose |
| --- | --- | --- | --- |
| Postgres + pgvector | `pgvector/pgvector:pg16` | **5432** | Primary OLTP + migrations |
| Redis Stack | `redis/redis-stack:7.4.0-v1` | **6379** | Rate limits, readiness probes |
| ClickHouse | `clickhouse/clickhouse-server:24.8` | **8123** (HTTP), **9002** (native) | Traces, usage facts, analytics |
| MinIO init | `alpine:3.21` | — | Initializes the MinIO data volume and exits successfully |
| MinIO | `cgr.dev/chainguard/minio:latest` | **9100** (API), **9101** (console) | Archive/object storage |
| Worker | built from `services/worker/Dockerfile` | **8006** (metrics), **8007** (enqueue/health) | Celery extraction, billing, deletion, and dead-letter tasks |
| Worker Beat | built from `services/worker/Dockerfile` | — | Scheduled task dispatch |

ClickHouse native is mapped to host port **9002**; MinIO uses host ports **9100** (API) and **9101** (console).

Host-run application services (started separately; Worker and Worker Beat are containerized above):

| Service | HTTP | gRPC | Notes |
| --- | --- | --- | --- |
| Proxy | **8080** | — | `/health`, `/ready`, `/metrics`, `/v1/*` |
| Auth | **8081** | **9091** | gRPC identity and policy methods |
| Management API | **8010** | — | FastAPI management and operator routes |
| Memory | **8005** | — | Memory write/search/feedback/forget |
| Embedder | **8004** | — | Embedding profiles and readiness |
| MCP memory | **8090** | — | Streamable HTTP MCP |
| MCP operator | **8091** | — | Streamable HTTP MCP, default-off |
| Console | **3000** | — | Nuxt operator UI |
| Context assembly | — | configured loopback | gRPC 3.5 assembly service |

## Make targets

```bash
make help              # list all targets
make compose-dev-up    # start infra/compose/dev stack
make compose-dev-down  # stop containers (keep volumes)
make compose-dev-reset # stop + delete volumes (fresh Postgres)
make compose-dev-ps    # container status
make compose-dev-logs  # tail dependency logs
make db-migrate        # apply pending migrations
make db-migrate-down   # roll back one step (dev only)
make db-seed           # idempotent dev org/agent/PAT
make dev-smoke         # end-to-end auth + proxy smoke
```

::callout
---
{"type":"warning","title":"Auth timeout on local machines"}
---

  Set `IBEX_AUTH_VALIDATE_TIMEOUT=2s` on the proxy for local dev. The production default (`50ms`) is often too low for Argon2 verification and returns **503** `SERVICE_DEGRADED` before agent checks run.

## Dev PAT from seed

After `make db-seed`, use the wire-form PAT from ADR-0007:

```text
ibex_pat_00000000-0000-0000-0000-000000000004_LOCALDEVELOPMENTONLY
```

Fixed IDs: org `…0001`, agent `…0003`. Full values print in the seed script output.
