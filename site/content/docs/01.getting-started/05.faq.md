## Setup

### What do I need installed?

Go 1.25+, Docker Desktop (or Docker Engine + Compose), `make`, and `pnpm` 9.x for the docs site. See [TOOLCHAIN.md](https://github.com/Rick1330/ibex-harness/blob/main/engineering/TOOLCHAIN.md) in the engineering docs.

### Which ports does local dev use?

| Service | Port |
| --- | --- |
| Proxy HTTP | 8080 |
| Auth HTTP / gRPC | 8081 / 9091 |
| Management API | 8010 |
| Memory | 8005 |
| Postgres | 5432 |
| Redis | 6379 |
| ClickHouse HTTP / native | 8123 / 9002 |
| MinIO API / console | 9100 / 9101 |
| Worker metrics / enqueue | 8006 / 8007 |

Boot the stack:

```bash
git clone https://github.com/Rick1330/ibex-harness.git
cd ibex-harness
make compose-dev-up
make db-migrate
```

These Make targets start the Compose stores and worker containers only; they do not start host-run auth, proxy, or
the other application processes. Export each host service's variables before its `go run` or Python start command;
copying an `.env.example` file does not load it.

## Security

### Does the proxy fail open on rate limits?

No. If shared Redis is unreachable, the Proxy returns `503 SERVICE_DEGRADED` and does not call the provider. Only local development may omit `REDIS_URL` and use the explicit Noop limiter; see [ADR-0081](https://github.com/Rick1330/ibex-harness/blob/main/engineering/adr/0081-fail-closed-proxy-runtime-controls.md).

### Does agent verification fail closed?

Yes. A missing or cross-org `X-IBEX-Agent-ID` returns `403` before the request reaches provider logic.

## Capability boundary

### Why do I sometimes see `501 PROVIDER_NOT_CONFIGURED`?

That code means the **model id is not registered** in the active provider registry (typo, or missing from defaults / `IBEX_LLM_EXTRA_MODELS`). In non-production environments, default `IBEX_LLM_MODE=mock` returns HTTP **200** for registered models. Mock mode is rejected when `IBEX_ENV=production` — use `IBEX_LLM_MODE=live` with `OPENAI_API_KEY` for live forwarding. See [Provider adapters](/docs/proxy/provider-adapters) and [Chat completions](/docs/api-reference/chat-completions).

### Where is the Console?

The Console and management API exist but are **provisional** operator surfaces. Hosted operator runtime topology, PolicySnapshot resource evaluation, and durable evidence-grade audit remain open. See [Status and evidence](/docs/architecture/status-and-evidence).
