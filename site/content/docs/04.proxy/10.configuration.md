The proxy loads configuration from environment variables at startup via `packages/config`. There is no `config.yaml` — missing required values panic with a clear message so misconfiguration surfaces before the first request, not during traffic.

Copy `services/proxy/.env.example` to `services/proxy/.env` for local development. The canonical registry is `engineering/ENVIRONMENT_VARIABLES.md` §9–10.

::callout
---
{"type":"tip","title":"Local dev timeout"}
---

  Set `IBEX_AUTH_VALIDATE_TIMEOUT=2s` on developer machines. The production default `50ms` is often too tight for Argon2 token verification over loopback; without the override, bearer requests may return `503 SERVICE_DEGRADED`.

::

## Required variables

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `IBEX_ENV` | `enum` | Yes | Explicit runtime profile: development, staging, or production. Startup rejects an unset/empty value instead of assuming development. |
| `IBEX_AUTH_GRPC_ADDR` | `string (host:port)` | Yes | Auth service gRPC target for ValidateToken and ValidateAgent. |
| `REDIS_URL` | `string (URL)` | No | Shared Redis for rate limiting, auth-cache revocation subscribe, idempotency, and /ready; required outside development and optional for explicit development Noop mode. |

## Provider modes

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `IBEX_LLM_MODE` | `enum` | No | `mock` (deterministic in-process provider, default) or `live` (real upstreams). Mock is forbidden when IBEX_ENV=production. |
| `OPENAI_API_KEY` | `string` | No | Required when IBEX_LLM_MODE=live. |
| `OPENAI_BASE_URL` | `string (URL)` | No | OpenAI-compatible API base. |
| `IBEX_LLM_EXTRA_MODELS` | `string` | No | Comma-separated extra model ids registered for routing. |

## Postgres features (directives / sessions)

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `POSTGRES_DSN` | `string (postgres://…)` | No | Enables directive load and session store. Empty → Noop directive/session behavior. |
| `IBEX_DIRECTIVE_CACHE_TTL` | `duration` | No | Directive Redis cache TTL. |
| `IBEX_SESSION_CACHE_TTL` | `duration` | No | Session Redis cache TTL. |
| `IBEX_SESSION_IDLE_TIMEOUT` | `duration` | No | Idle session sweeper threshold. |

## Auth cache

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `IBEX_AUTH_CACHE_ENABLED` | `boolean` | No | Wrap ValidateToken with bloom+LRU when Redis is healthy. Skipped (WARN) if Redis URL empty or Ping fails. |

See [Auth caching](/docs/proxy/auth-caching).

## Idempotency and traces

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `IBEX_IDEMPOTENCY_TTL` | `duration` | No | Redis Idempotency-Key TTL for non-streaming chat. |
| `CLICKHOUSE_DSN` | `string` | No | Empty disables async llm_traces writer (fail-open). |
| `CLICKHOUSE_INSERT_BATCH_SIZE` | `integer` | No | Trace batch size before flush. |
| `CLICKHOUSE_INSERT_FLUSH_MS` | `integer` | No | Max flush interval in milliseconds. |

## HTTP and auth tuning

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `IBEX_PORT` | `integer` | No | HTTP listen port. |
| `IBEX_AUTH_VALIDATE_TIMEOUT` | `duration` | No | Per-request ValidateToken deadline. |
| `IBEX_MAX_REQUEST_BODY_BYTES` | `integer` | No | Maximum chat completion JSON body size. |
| `IBEX_SHUTDOWN_TIMEOUT` | `duration` | No | Graceful drain window on SIGTERM. |

## Rate limiting

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `IBEX_RATE_LIMIT_DEFAULT_RPM` | `integer` | No | Requests per minute for orgs without an override. |
| `IBEX_RATE_LIMIT_ORG_OVERRIDES` | `string` | No | Comma-separated org_uuid=rpm pairs for tenant-specific budgets. |

Redis keys follow `ratelimit:{org_id}:rpm:{unix_minute}` — org_id is always the second segment per [Tenant isolation](/docs/security/tenant-isolation).

## Example `.env` excerpt

```bash title="services/proxy/.env"
IBEX_PORT=8080
IBEX_AUTH_GRPC_ADDR=127.0.0.1:9091
IBEX_AUTH_VALIDATE_TIMEOUT=2s
IBEX_LLM_MODE=mock
REDIS_URL=redis://localhost:6379/0
POSTGRES_DSN=postgres://ibex:ibex@localhost:5432/ibex?sslmode=disable
IBEX_MAX_REQUEST_BODY_BYTES=1048576
IBEX_RATE_LIMIT_DEFAULT_RPM=60
IBEX_LOG_LEVEL=debug
```

Smoke-test convenience variables (`IBEX_DEV_TOKEN`, `IBEX_DEV_AGENT_ID`) are documented in `.env.example` but are **not** read by the proxy binary — they exist for `make dev-smoke` only.

## Readiness dependencies

`GET /ready` reports critical dependency health:

| Check | When evaluated | Failure impact |
| --- | --- | --- |
| `auth_grpc` | Always | Orchestrator should not route traffic |
| `redis` | Always | `/ready` fails; in development an explicit Noop limiter may still admit requests |

Liveness (`GET /health`) does not probe dependencies — use it for process-up checks only. Details: [ADR-0022](https://github.com/Rick1330/ibex-harness/blob/main/engineering/adr/0022-health-check-contract.md).

## Boot order

::steps

### Infrastructure

    `make compose-dev-up` — Postgres, Redis, optional ClickHouse.
  
### Migrations and seed

    `make db-migrate && make db-seed` — org, agent, and dev PAT for smoke tests.
  
### Auth first

    Start auth on gRPC `9091` before the proxy. See [Environment variables](/docs/deployment/environment-variables).
  
### Proxy

    `go run ./services/proxy/cmd/proxy` with env from `.env`.
  
::
