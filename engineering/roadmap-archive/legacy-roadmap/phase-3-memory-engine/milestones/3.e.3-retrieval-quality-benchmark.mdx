## CI Wiring

`.github/workflows/memory-benchmark.yml`:

| Job | Purpose |
|---|---|
| `collect-hnsw-benchmarks` | HNSW recall/latency + **gate status enforcement** + schema validate |
| `collect-ranking-quality` | Gold-set ranking bench + regression gate |
| `collect-write-pipeline-bench` | Write orchestrator wall-clock p95 + regression gate |

Profiles: `smoke` (PR), `fast` (main push), `full` (weekly cron) for HNSW sizes.

---

## Sign-Off Gate

| Metric | Threshold | Enforced by |
|---|---|---|
| HNSW recall@10 (published cells) | ≥ 98% | `check_hnsw_gate_status.py` on `gate_summary` |
| Vector search p99 at 1M (when cell present) | < 100ms | same |
| Write pipeline p95 (`orch.create()` wall-clock) | < 200ms | `write_pipeline/regression_gate.py` SLA |
| Ranking precision@5 / recall@10 / MRR | ≥ baseline − 5% | `ranking_quality/regression_gate.py` |
| Gold set | v1 single-labeler | See [ranking_quality README](https://github.com/Rick1330/ibex-harness/blob/main/benchmarks/memory/ranking_quality/README.md) |

Category-decay regression queries in gold set v1: `q_pref_theme_decay`, `q_workflow_deploy_decay`, `q_confidence_tie_break` (distinct from 3.D.2 dark-mode pair).
