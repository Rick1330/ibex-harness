<Callout type="note" title="Design note (sketch deviations)">
  Shipped shape differs from the early sketch in these locked ways:

  1. **`OrgAwareRegistry` wraps `*provider.Registry`** — `Registry.For(model)` signature unchanged; org gate is `ForOrg(ctx, orgID, model)`.
  2. **Real middleware change** — `ProviderRoutingMiddleware` fills empty model from agent `default_model` (proxy Postgres), then calls `ForOrg`; handlers unchanged.
  3. **Not authcache** — dedicated LRU+TTL in `packages/modelpolicy` with **60s TTL + Redis pub/sub only** (no 30s full poll sibling; no ornamental bloom).
  4. **No `fallback_chain`** column — deferred until 4.C.4 has a consumer ([ADR-0075](/docs/adr/0075-per-org-model-routing-policy)).
  5. **Agent defaults via proxy Postgres** — Auth gRPC / `ValidateAgent` unchanged; `default_provider` ignored for routing.
  6. **Policy load errors → 503 fail-closed** (do not silently allow when the policy plane is broken).
  7. **Admin CRUD shipped** — `GET/POST/PATCH/DELETE /v1/organizations/{org_id}/model-policies` with `RequireOrgSettings` on writes.
  8. Glob = Go `filepath.Match` only; soft pattern validation on write (not live registry / #790).
</Callout>

## Why This Milestone Exists

Exit criteria requires model-based routing configuration per org — allowlists/denylists and default-model overrides (e.g. enterprise restricted to Anthropic for compliance). Platform registry remains the source of which models exist; org policy is a veto gate before `Registry.For`.

## Non-Goals

- Generic rules engine / DSL
- Per-user model routing
- Azure OpenAI or Bedrock adapters
- Auth service changes
- `fallback_chain` (4.C.4)
- Strict provider allowlist (#790)

## Shipped surface

| Layer | What landed |
|-------|-------------|
| ADR | [ADR-0075](/docs/adr/0075-per-org-model-routing-policy) |
| Schema | Migration `000029_org_model_policies` (RLS; no `fallback_chain`) |
| Domain | `packages/modelpolicy` — store, evaluate, LRU+TTL, publisher/subscriber, `OrgAwareRegistry` |
| Proxy | Chat parse allows empty model; `ProviderRoutingMiddleware` + bootstrap subscriber |
| Errors | `403 MODEL_NOT_ALLOWED`; unknown after allow still `501 PROVIDER_NOT_CONFIGURED` |
| API | Org-scoped model-policies CRUD + `model_policy_updates:{org_id}` publish-on-write |

### Precedence

1. Request `model` (trimmed) if non-empty
2. Else agent `default_model` from proxy Postgres
3. Else `400` model required
4. Org policy first-match (priority ASC, `filepath.Match`); no match → allow
5. `Registry.For(candidate)` → attach provider or `501`

### Channels

- `model_policy_updates:{org_id}` / `model_policy_updates:*`
- Payload: `{"v":1,"org_id":"<uuid>"}`
