# Architecture Decision Records

This directory is the canonical source for IBEX Harness architecture decisions. ADRs are engineering records, not public documentation pages.

- **Browse:** <https://github.com/Rick1330/ibex-harness/tree/main/engineering/adr>
- **Convention:** `NNNN-short-slug.md`, sequential numbering, immutable accepted decisions.
- **Required sections:** Context, Decision, Consequences, References.
- **Superseding:** add a new ADR; do not rewrite an accepted record silently.
- **Evidence:** link runtime evidence to the public status ledger, not to an ADR alone.

Public documentation links to individual records by repository URL. The site does not render an ADR section.
